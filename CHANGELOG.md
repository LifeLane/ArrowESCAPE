# Changelog

All notable changes to **Arrow Escape** (`com.mitsara.arrowescape`) will be documented in this file.

## [1.0.0] - 2026-08-27

### Added
- Official launch release of Arrow Escape logic puzzle game.
- 500+ hand-crafted & procedurally generated 4x4 to 8x8 spatial logic levels.
- Deterministic BFS solver engine guaranteeing 100% solvability.
- Daily calendar challenges with date-seeded puzzles (YYYYMMDD) & streak tracking.
- 4 Custom Visual Themes (Classic Light, Midnight Dark, Cyber Neon, Warm Wood).
- AdMob integration (Banner, Interstitial, Rewarded, Native, Entry/Exit, Full Page Rewarded).
- RevenueCat entitlement support & Play Store billing status.
- Offline Room database persistence.
- Complete GitHub Actions CI/CD workflows for Debug, Release, Security, and Play Store Publishing.
