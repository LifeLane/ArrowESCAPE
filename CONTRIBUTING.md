# Contributing to Arrow Escape

Thank you for your interest in contributing to **Arrow Escape** (`com.mitsara.arrowescape`)!

## Development Guidelines

1. **Identity Integrity:**
   - Never change the `applicationId`, `namespace`, or package name (`com.mitsara.arrowescape`).
2. **Quality Gates:**
   - Run `./gradlew lintDebug` and `./gradlew testDebugUnitTest` before submitting a pull request.
3. **Gradle Wrapper:**
   - Always use `./gradlew` (never system Gradle).
4. **Code Style:**
   - Follow standard Kotlin and Jetpack Compose clean architecture conventions.
